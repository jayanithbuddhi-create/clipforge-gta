Come si usa

  1. Non devi fare niente: ogni 20 minuti lo Scout controlla gli streamer. Se uno è in live su GTA, registra 10 minuti e monta le clip migliori.
  2. Pubblica: tocca Condividi su una clip e scegli TikTok, Instagram o "Salva video".
  3. Clippa subito un link: tocca Clippa un link ora → Run workflow → incolla il link Twitch (live o VOD) → Run workflow. Le clip arrivano qui in circa 15 minuti.
  4. Cambia streamer o facecam: modifica config.json (facecam: tl, tr, bl, br o none).
