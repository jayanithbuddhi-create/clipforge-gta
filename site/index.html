Tempo reale (facoltativo)

Non serve per clippare: "Clippa" funziona già, basta toccare Create su GitHub. Con una chiave GitHub invece gli agenti si aggiornano ogni pochi secondi e le live partono con un tocco solo. La chiave resta salvata solo su questo telefono.

  1. Apri questa pagina di GitHub.
  2. Token name: scrivi ClipForge. Expiration: scegli 1 anno.
  3. Repository access: Only select repositories → clipforge-gta.
  4. Permissions → Repository → Actions: Read and write.
  5. Tocca Generate token, copia il codice (inizia con github_pat_) e incollalo qui sotto.
